03 / DESIGN INTENT

A ritual, not
a reminder.

Seven Signals turns a deadline into a visible route. Seven orbiting beacons represent the steps before launch. Every new day lights up another checkpoint and changes the one action in focus. A gently mapped landscape suggests progress instead of panic. The top of each wallpaper is intentionally quiet so the phone's real clock, widgets and notifications remain usable.

Use it: download today's PNG, set it as your lock screen, complete its single action, then replace it with the next day's image. Keep the live webpage as a precise time-remaining reference.

Made with: ChatGPT for concept/planning, custom Python/Pillow artwork, and HTML/CSS/JavaScript for the live companion. The original Handshake lesson introduces Google Gemini; this project does not claim to have used it.
